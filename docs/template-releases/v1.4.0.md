# htmlapps-template v1.4.0

## 日本語

Browser Kittyの共通UI・UXとリリース前検証を更新したテンプレートです。

- EN/JA・ヘルプの枠なしヘッダー、スマホ向けタップ領域、簡潔な説明、枠なし集計表示、SVG付き操作ボタン、ヘルプ内のビルド情報。
- ファイル選択・保存、進捗、操作バー、メディアプレビュー、範囲指定、モード切替、空状態、全画面、画像比較の10部品を追加。既存のメディア選択補助を含む全18部品のガイドを整備。
- ローカル保存の失敗表示、Undo、コピー、ファイル名、Blob URL、非同期処理の競合を改善。
- WebRTCの正方形QRガイド、カメラ切替・停止、ICE診断、古いQR処理の無効化、準備完了用DataChannelの接続判定を改善。
- リポジトリルートHTML生成、PR Preview、固定依存・単一HTMLの検証を維持。設定済みアプリのmain限定リリース、ハッシュ検証、公開済みReleaseの保護、3ブラウザの検査を追加。
- 日英README、仕様、部品ガイド、オフライン確認、ライセンス情報、セキュリティと開発手順を整備。

配布用ソースは `htmlapps-template.zip`。通常版と自己展開版のHTMLはビルドで生成します。スターターの仮リポジトリ設定は維持しているため、派生アプリ向けの自動リリースはこのテンプレート自体を公開しません。

検証範囲：Chromium / Firefox / WebKit、日英、320/390/740/1360px、通常版・自己展開版、保存/Undo/異常系、外部HTTP(S)通信、共通部品、模擬GitHub API、ソースZIP整合性。実際の検査結果はPR Checksを参照してください。スマホ実機のファイル選択・共有・カメラ・端末間QR接続、実際のGitHub Release公開は別途確認が必要です。

## English

This template release refreshes the shared Browser Kitty UI and release verification.

- Compact unboxed EN/JA and help controls, mobile touch targets, concise introduction, inline counters, SVG action buttons and build information inside Help.
- Ten new reusable file, export, progress, action, media, range, segmented, empty-state, fullscreen and image-comparison snippets; documentation for all 18 components including the existing compact media fallback.
- Correct local-storage failure reporting, Undo, clipboard fallback, filename handling, Blob URL lifetime and asynchronous races.
- Square WebRTC QR guide, camera lifecycle and switching, ICE diagnostics, stale QR guards and designated DataChannel readiness handling.
- Preserve repository-root HTML generation, PR Preview, pinned embedded dependencies and standalone verification. Add main-only release publishing for configured apps, checksum validation, immutable published releases and cross-browser regression tests.
- Synchronize bilingual READMEs, specifications, component guides, offline checks, license information, security and development guidance.

The source distribution is `htmlapps-template.zip`; the build generates readable and self-extracting HTML. Placeholder repository settings remain intentional, so the application release workflow does not publish the template itself.

Verification scope: Chromium, Firefox and WebKit; Japanese and English; 320/390/740/1360px; both HTML variants; export, Undo, failure handling, external HTTP(S) requests, component behavior, mocked GitHub API and source ZIP consistency. See the PR checks for actual results. Real phone file picking, sharing, camera and device-to-device QR pairing, and actual GitHub Release publishing still require separate verification.
